# Professional Portfolio (Angular)

This is an Angular starter portfolio site designed for experienced/professional candidates.

## What is included

- Hero section with candidate introduction
- Core skills section
- Experience timeline cards
- Featured projects section

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run dev server:
   ```bash
   npm start
   ```

Open `http://localhost:4200/`.
